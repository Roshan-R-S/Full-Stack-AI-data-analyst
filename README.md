# Full Stack AI Data Analyst

A full-stack AI-powered data analytics application.

## Stack
- FastAPI + Python
- Pandas + NumPy
- Gemini API
- React + TypeScript + Vite
- Tailwind CSS
- Nothing-inspired UI design

## Status
Phase 1: Foundation.

Feature module files are scaffolds and will be implemented
in subsequent development phases.

## Backend
From the backend directory:

    uv sync
    uv run uvicorn app.main:app --reload --port 8000

## Frontend
From the frontend directory, install dependencies first,
then run:

    npm run dev
